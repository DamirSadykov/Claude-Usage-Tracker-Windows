Описание

Склейка источников: блоки task_sessions дают сессию и интервал, по идентификатору выбирается разбор Claude или codex, события run-events.jsonl этой задачи группируют сессии в попытки. Риск — сессия, поделённая между задачами: в дерево идут только ходы внутри интервала блока, иначе задача покажет чужую работу. Кэш по (путь, размер, mtime), чтобы повторное открытие карточки не перечитывало файлы.
