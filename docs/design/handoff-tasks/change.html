Карточка задачи показывает только итог. Нужно видеть, как шла работа: какие сессии и попытки были, какие вызовы модели и инструментов, где родились субагенты и во что обошёлся каждый шаг. Источники — транскрипты Claude Code и rollout codex, склеенные по интервалам task_sessions.

Входит
  • Разбор обоих форматов в общее дерево
  • Команда get_task_work_tree с кэшем
  • Trace во вкладке задачи: график, фильтры, инспектор
  • Флаг контекста у сессий и субагентов
Не входит
  • Граф прогонов между задачами — c#70
  • Редактирование транскриптов
  • Экспорт trace
Готово, когда
  • Дерево собирается для Claude и codex
  • У каждой сессии видно, с каким контекстом она стартовала
  • Сессия, общая для двух задач, не показывает чужую работу
  • Повторное открытие карточки не перечитывает файлы
  • Дерево проверено вручную на реальных задачах в окне
