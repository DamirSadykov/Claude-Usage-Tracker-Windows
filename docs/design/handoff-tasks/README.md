# Handoff: раздел задач — дерево, карточка, trace

Состав: `tasks.html` (статичная вёрстка, кадры `#fTA` — дерево + карточка, `#fTB` — trace), `tasks.css` (стили экранов), `win11.css` (токены), `change.html` + `change.css` (карточка change, `#fTC`, поверх `tasks.css`), `screens/` (как выглядит).
Новых цветов не вводить — всё из `win11.css`.

---

## C. Карточка change (`change.html`)

Открывается кликом по строке change в дереве. Крошки `проект › c#N`, справа `‹ 2 / 3 change ›`.
- Шапка: `c#N` жёлтый + title; статус Открыт/Закрыт (сегмент); чипы `done/total задач`, `$spent / $budget`, `с дата · N дн.`; `Открыть в графе`, `⋯`.
- Вкладки: Обзор · Trace (сумма по всем задачам) · Комментарии.
- **Бриф** — карточка: абзац «зачем» → Входит (+) / Не входит (–, ссылки на другие change) → Готово, когда (✓ / ○). Поле `brief` в change; `Редактировать` открывает markdown-редактор.
- **Задачи** — таблица `статус | # | задача | вид | попытки | $ с мини-баром (доля от самой дорогой) | время`, порядок по зависимостям. Клик по строке → карточка задачи; на hover справа `Trace ↗` — сразу во вкладку Trace. Кнопка «Дерево работы» на каждой строке и «нет данных» убраны.
- Правая колонка: Бюджет (исполнитель/ревью), Прогресс (попытки, возвраты с ревью, что осталось), Дорогие задачи (топ-3).

---

## 0. Что чиним (боли → решение)

| Боль | Решение |
|---|---|
| change раскрывается только по иконке | клик в любом месте строки дерева раскрывает/сворачивает её; выбор задачи — клик по строке задачи |
| второй список задач | остаётся одно дерево слева; в карточке change список задач не дублируется |
| из карточки задачи назад только через change → задачи | хлебные крошки `проект › c#N title › #N` (каждый сегмент кликабелен) + `‹ N / M ›` по задачам того же change |
| в карточке потерялся шрифт из настроек | карточка и trace наследуют шрифт/размер из настроек через те же CSS-переменные, что и дерево; никаких локальных `font-family` |
| счётчик «прилипает» к тексту | done/total и $ — отдельные колонки грида, выравнивание вправо, `tabular-nums` |
| ref-ссылки не используются | убраны; вместо них блоки «Зависит от» / «Блокирует» из `depends_on[]` |

## 1. Каркас экрана

```
appbar 50px   | Задачи · [Мои|Внешние N] · [Дерево|Волны|Граф] · поиск · фильтры-чипы · + Задача
body          | tree (392px, #1a1a1a) | pane (1fr)
pane          | crumbs 40px · head (title, meta, tabs) · scroll
```

Фильтры — чипы: пустой `+ Проект` (dashed), активный `Статус: не готово ✕` (accent-soft + accent). Заменяют ряд селектов и чекбокс «Показать готовые».

## 2. Дерево (`.tree`)

Строка 30px, grid: `14px (caret) | 1fr (id + title) | 62px (готово) | 54px ($)`; отступ `10px + level*16px`.
Шапка колонок: `Проект · change · задача | готово | $` (10px uppercase, `--text-4`).

| Уровень | Вид |
|---|---|
| project (l0) | mono 12px 600, `--text`; готово `done/total`; $ суммой (раньше не показывалась) |
| change (l1) | `c#N` mono жёлтый `#e3b341`, заголовок `--text`; полоска прогресса 2px под строкой (жёлтая, 70%); закрытые — `opacity .55`, свёрнуты |
| группа «Без change» (l1) | 10px uppercase `--text-4`, после всех change |
| task (l2 / l1 без change) | точка статуса 8px + `#N` mono `--text-3` + subject; колонка готово пустая |

Статус-точки: `done` зелёная · `in_progress` accent + ореол 3px · `review` фиолетовая `#b388ff` · `queue` обводка `--text-3` · `backlog` пунктир `--text-4`.
Выбранная: `--accent-soft` + inset 2px слева accent, `#N` accent.
Готово = total → зелёный `#8fdc84`. $ — `#e79878`.
Сортировка без изменений: открытые change выше, затем по активности. Футер дерева: `200 активных · 550 всего · $итого`.

## 3. Карточка задачи (`#fTA`)

**Крошки** (40px): project mono → `c#N` жёлтый + title → `#N` белый; справа `‹ 3 / 11 ›` (кнопки 26×24). Сегменты hover `--layer`.

**Шапка:** `#N` mono `--text-4` + subject 22px/600. Ряд meta:
- статус — сегментированный контрол из 5 значений (активный: зелёная подложка для done, accent для in_progress); заменяет select;
- чипы: приоритет, kind, `$1.59` (money), попытки `2 попытки · прошла`;
- `⋯` справа — меню с «Удалить» (кнопка удаления больше не на виду).

**Вкладки:** `Обзор` · `Trace $X · N вызовов` · `Комментарии N`. Счётчики в табах mono `--text-4`.

**Обзор** — grid `1fr | 300px`, gap 22:
- слева: Описание (13.5/1.62, max 780px) → Handoff карточкой с подписями `Сделано / Подвох / Дальше` (колонка 78px) → последние 2 комментария (аватар 26px, severity-метка `high`/`medium` из текста ревью, чип «попытка 1/2 · ревью»);
- справа: карточка Change (`c#N`, title, прогресс, потрачено / budget_usd + полоса) → «Зависит от» / «Блокирует» (строки с точкой статуса, клик = переход) → «Стоимость по сессиям» (исполнитель / ревью, двухцветная полоса).

## 4. Trace (`#fTB`)

Дерево слева сужается до 300px (без колонки «готово»).
Справа в табах: `Только заголовки`, `Транскрипт ↗`.

**Чипы-фильтры типов** (заменяют таблицу «Тип / Вызовов / Стоимость / Доля» и чекбоксы): `● тип · N · $ · %`. Выключенный — `opacity .45`, без фона. Типы с 0 вызовов — выключены по умолчанию.

| Тип | Цвет |
|---|---|
| чтение (read) | `#4cc2ff` |
| правка (edit) | `#6ccb5f` |
| shell | `#b388ff` |
| текст | `#8a8a8a` |
| субагент (agent) | `#f0a0c8` |
| web / прочее | `#e79878` / `--text-4` |

**График** (один вместо двух, фон `#161616`, высота ~118):
- столбцы — контекст на вызов модели, цвет = тип;
- линия `#e79878` 1.8px — стоимость накопленно (подпись итога справа);
- пунктир белый 35% — чтение кэша накопленно (своя шкала);
- вертикальные пунктиры с подписями: границы попыток/сессий (`П1 · исполнитель`, `П1 · ревью`, `П2 …`) и события `compacted`;
- клик по столбцу выбирает вызов в списке и в инспекторе; выбранный — белая рамка.

**Split** `1fr | 380px`:

Список, строка 28px, grid `1fr | 108px контекст | 52px $ | 44px время`, отступ `12 + level*18px`:
- Попытка (32px, 600, фон `rgba(255,255,255,.025)`) + чип итога ревью (`ревью: 2 замечания` красный / `прошла` зелёный);
- Сессия: роль + id mono + метка контекста (`чистый контекст` accent-soft, `наследует …` фиолетовая, `continued`, `compacted`);
- Вызов модели: имя + `модель · N вызовов`;
- Группа: `#4–7 · тип · Get-Content ×4`, свёрнута;
- Tool: `#N` + чип типа + input одной строкой mono, обрезка многоточием. Строка «Script completed» не выводится — результат только в инспекторе;
- Субагент: чип `субагент` + название, раскрывается рекурсивно;
- «Ручные сессии» — последней строкой уровня 0.
Контекст: мини-бар 40×4 (доля от окна модели) + `19.0k`.

Инспектор (карточка `--layer`): заголовок `чип типа · #N · имя модели-вызова · длительность` → Ввод (pre, `#161616`) → Ответ (+ `✓ exit 0`) → Токены: стековая полоса + таблица `вход / чтение кэша / запись кэша / выход` с количеством и $ по каждой ставке → «Итого вызов $» → кнопки `Показать транскрипт`, `Копировать ввод` прижаты вниз.

«Только заголовки»: скрывает строки tool и группы, оставляет попытки, сессии, вызовы модели.

## 5. Данные → UI

| Поле | Где |
|---|---|
| project: done/total, Σ cost | колонки дерева l0 |
| change: number, title, done/total, Σ cost, budget_usd, closed_at | строка l1, полоска прогресса, карточка Change |
| task: status, priority, kind, depends_on[], cost, outcome, status_history | точка статуса, meta-чипы, Зависит/Блокирует, чип попыток |
| «Блокирует» | обратный индекс по depends_on задач того же проекта (не хранится) |
| attempt: started/ended, события | строка попытки, вертикальные метки графика |
| session: worker/review, метка контекста, модель, cost, tokens | строка сессии |
| model call: tokens ×4, cost | столбец графика, инспектор |
| tool: #, type, input/result | строка tool, инспектор |

Стоимость суммируется вверх на каждом уровне; время — `ended − started`, формат `48s / 9m / 2h 11m`.
