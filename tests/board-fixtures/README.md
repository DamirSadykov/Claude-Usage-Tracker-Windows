# Фикстуры файла доски

Образцы `todos.json` под контракт `docs/specs/tasks/spec.md#board-file`.
Они общие для CLI и приложения. CURRENT обоих писателей — `version: 3`.

`board.schema.json` генерируется Rust-типами. Node проверяет все годные
фикстуры этой схемой через Ajv.

## Список фикстур

| Файл | Назначение |
|---|---|
| `v1/empty.json`, `v1/full.json` | форма до миграции 1→2 |
| `v2/empty.json`, `v2/full.json` | форма 2: поля процесса находятся на верхнем уровне и при записи переходят в v3 |
| `v2/unknown-field.json` | непрозрачный `ext` и неизвестное верхнеуровневое поле |
| `v2/future-version.json` | файл версии 99 |
| `v3/empty.json`, `v3/full.json` | текущая форма; поля процесса есть только в `ext.process` |
| `corrupt/mixed-v2-v3.json` | одно поле одновременно наверху и в `ext.process` |
| `corrupt/truncated.json`, `corrupt/not-object.json`, `corrupt/todos-not-array.json`, `corrupt/empty-file.json` | синтаксическая или структурная порча |
| `corrupt/todo-field-type.json` | несовпадение типа поля узла |

## Матрица совместимости «версия писателя × версия файла»

| Файл | CLI v3 | Приложение v3 |
|---|---|---|
| `v1/*.json` | читает, но не пишет: миграция 1→2 остаётся за приложением | читает, мигрирует и сохраняет как v3 |
| `v2/empty.json` | читает, сохраняет как v3 | читает, сохраняет как v3 |
| `v2/full.json` | читает; переносит все поля процесса в `ext.process` при сохранении v3 | то же |
| `v2/unknown-field.json` | сохраняет `ext` и неизвестное верхнеуровневое поле | сохраняет `ext` без изменений, неизвестное верхнеуровневое поле отбрасывает |
| `v2/future-version.json` | читает известные поля, запись отказывает | то же |
| `v3/empty.json` | без потерь | без потерь |
| `v3/full.json` | без потерь | без потерь |
| `corrupt/mixed-v2-v3.json` | нечитаем: создаёт один бэкап, запись отказывает | нечитаем: создаёт один бэкап, запись отказывает |
| прочие `corrupt/*.json` | восстановление; запись отказывает | восстановление; запись отказывает |

`ext` — пространство непрозрачных модулей и сохраняется целиком. Поле вне
`ext`, которое писатель не знает, Rust отбрасывает, а CLI переносит как есть.
Файлы, где одно поле процесса одновременно записано на верхнем уровне и в
`ext.process`, не имеют выбранного победителя: обе стороны отказываются их
читать и никогда не выбирают значение молча.

Сравнение round-trip идёт по разобранным JSON-значениям, не по байтам.
